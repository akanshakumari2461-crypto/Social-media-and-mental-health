# Social Media Screen-Time & Mental-Health Wellbeing Predictor

A machine-learning web application that predicts a user's **wellbeing band** (Good / Moderate / At-risk) based on their social-media habits, screen-time patterns, and mental-health self-assessments.

---

## Dataset

`data/dataset.csv` — *Social Media Screentime & Mental Health 2026*
- 7,000 participants
- 24 features: demographics, platform usage, sleep, mental-health scores, and behavioural habits
- Target: `wellbeing_band` (Good · Moderate · At-risk)

## Local Setup

### 1. Clone / download the repository

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```

### 2. Create a virtual environment and install dependencies

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Train the model

```bash
python train_model.py
```

This compares four classifiers (Logistic Regression, Decision Tree, Random Forest, Gradient Boosting) via 5-fold cross-validation, selects the best, and saves the full pipeline to `models/model.pkl`.

### 4. Run the app

```bash
streamlit run app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

## Streamlit Community Cloud Deployment

1. Push the project to a **public** GitHub repository.
2. Go to [share.streamlit.io](https://share.streamlit.io) and click **New app**.
3. Select your repo, branch (`main`), and set the **Main file path** to `app.py`.
4. Click **Deploy**.

> **Important:** `models/model.pkl` must be committed to the repository (or you must run `python train_model.py` as part of a setup hook). The simplest approach is to commit the generated `model.pkl` file.

## Models Compared

| Model | Notes |
|---|---|
| Logistic Regression | Baseline linear classifier |
| Decision Tree | Interpretable non-linear classifier |
| Random Forest | Ensemble of 200 trees |
| Gradient Boosting | Sequential boosting, often top performer |

The best model is selected automatically by 5-fold stratified cross-validation and reported in the sidebar of the app.
